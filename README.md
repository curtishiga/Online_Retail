## Overview
The goal behind this project is to use an e-commerce business' data to help stakeholders gain actionable insights on their customers for greater success. The first is by performing RFM analysis to cluster customers into distinct buckets based upon similar behaviors and coming up with business strategies for each one. The second is identifying which customers are likely to churn, based on a machine learning model, and coming up with methods to encourage further engagement.

## Business Practices
**RFM Analysis**: Recency, Frequency, and Monetary analysis on customers to help stakeholders define patterns within their users.

**Customer Clustering**: Grouped/clustered customers based on RFM analysis into distinct buckets using an unsupervised k-nearest neighbors model.

**Churn Prediction**: Predict customer churn based on purchase patterns using machine learning classification models.

**Churn Dashboard**: Tableau dashboard ([link](https://public.tableau.com/views/E-CommerceCustomerRetention/E-CommerceCustomerRetentionDashboard?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)) to visualize churn metrics, trends, and define actionable insights for stakeholders.

## Data
This project takes on a real dataset taken from the University of California Irvine Machine Learning repository, linked [here](https://archive.ics.uci.edu/dataset/352/online+retail). It represents a year-and-a-half worth of transactional data from a UK based online retail company with more than 500K rows.
